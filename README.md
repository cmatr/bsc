# Blue Shell Consulting website

A responsive, dependency-free static corporate website.

## Preview locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

The site can be deployed directly to GitHub Pages, Netlify, or any static host. No build step is required.

Before publishing, review the service descriptions and company claims in `index.html` and replace them with the final approved copy.
